لعبة أنقذوا البريمو بجدول الضرب

طريقة التشغيل: افتح index.html في المتصفح.
للنشر: ارفع جميع محتويات المجلد إلى جذر مستودع GitHub ثم فعّل Settings > Pages > Deploy from a branch > main > /(root).
لا تحتاج اللعبة إلى خادم أو قاعدة بيانات. تقدم اللعب لا يتم تخزينه، والشهادة قابلة للطباعة أو الحفظ PDF.
ملاحظة: رسم الخزان والشخصية مأخوذ كمرجع بصري من تسجيل المستخدم المرفق. هذه إعادة بناء مستقلة وليست النسخة الأصلية.
